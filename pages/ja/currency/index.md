# 通貨と為替レート
<!-- position: 6 -->
<!-- description: 既定通貨、為替レートの自動取得・手動設定、カスタム通貨について説明します。 -->

このアプリでは、カテゴリごとに通貨を設定できます。総資産やグラフは、すべて**既定通貨**に換算して表示されます。

通貨の設定は「設定」タブ →「通貨・レート」で行います。

![通貨・レート画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/currency-settings.png)

## 使える通貨

| 種類 | 通貨 |
| --- | --- |
| 法定通貨 | 日本円、米ドル、ユーロ、英ポンド、豪ドル、カナダドル、スイスフラン、人民元、香港ドル、韓国ウォン、インド・ルピー、インドネシア・ルピア、ブラジル・レアル、シンガポール・ドル、ニュージーランド・ドル、カタール・リヤル、サウジアラビア・リヤル、UAEディルハム、マレーシア・リンギット、タイ・バーツ、トルコ・リラ、ロシア・ルーブル |
| 金 | 金（g）、金（ozt） |
| 暗号資産 | ビットコイン、イーサリアム |
| ポイント等 | ポイント、マイル |
| カスタム通貨 | ご自身で追加した通貨（後述） |

金・暗号資産・ポイント・マイルは、金額ではなく**数量**（例: 10 g、0.5 BTC、3,000 pt）で記録します。

## 既定通貨を設定する

既定通貨は、総資産・グラフ・資産目標を表示するときの通貨です。

1. 「設定」タブ →「通貨・レート」を開きます。
2. 「デフォルト通貨」の欄をタップします。
3. 回転式のピッカーで通貨を選び、「保存」をタップします。

「端末の設定に従う」を選ぶと、端末の言語に応じた通貨（日本語なら日本円、英語なら米ドルなど）が使われます。

## 為替レートの自動取得

既定通貨以外の通貨を使っているカテゴリがある場合、アプリはインターネットから最新のレートを取得して換算します。

- アプリの起動時に、自動でレートを取得します。
- 「入力」タブの総資産の右上にある更新ボタン（⟳）でも取得できます。
- レートの取得は**1日2回まで**です。上限に達した場合は「本日の更新回数の上限（1日2回）に達しています」と表示されます。
- ポイント・マイル・カスタム通貨のレートは自動取得されません。手動で設定してください。
- インターネットに接続できない場合は、アプリに内蔵された目安のレートや、前回取得したレートが使われます。

## 通貨レートを手動で設定する

「通貨・レート」画面の「通貨レート設定」には、カテゴリで使っている既定通貨以外の通貨と、カスタム通貨が表示されます。

![通貨レート設定](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/currency-rate-row.png)

1. 「1 USD → JPY」のように表示された入力欄に、1単位あたりの既定通貨の金額を入力します。
2. 右側の ✓ をタップして保存します。

入力欄の横の ⟳ ボタンをタップすると、その通貨の最新レートを取得して入力欄に反映できます（1日2回までの回数に含まれます）。取得に失敗した場合は、手動で入力してください。

> **ポイント**
> ポイントとマイルは、はじめは「1 pt = 1円」「1 mi = 1円」として換算されます。ご自身の価値の目安に合わせて変更してください。

## カスタム通貨を追加する

一覧にない通貨や、独自のポイントなどを「カスタム通貨」として追加できます。

1. 「通貨・レート」画面の「カスタム通貨を追加」をタップします。
2. 次の項目を入力します。

   | 項目 | 説明 |
   | --- | --- |
   | 表示名 | 通貨の名前です。 |
   | 通貨コード | 通貨を区別するためのコードです（例: MYCOIN）。ほかの通貨と同じコードは使えません。追加後は変更できません。 |
   | 単位 | 金額のあとに表示する単位です（例: マイル）。未入力の場合は通貨コードが表示されます。 |
   | レート | 1単位あたりの既定通貨の金額です。未入力の場合は 1 になります。 |

3. 「保存」をタップします。

追加したカスタム通貨は、カテゴリの通貨として選べるようになります。
一覧の鉛筆のアイコンで編集、ゴミ箱のアイコンで削除できます。

> **ご注意**
> カスタム通貨の削除は、確認なしですぐに実行されます。使用中のカスタム通貨を削除すると、そのカテゴリの金額が正しく換算されなくなる場合があります。

## 「一部の通貨のレートを取得できず、合計に反映されていません」と表示されたら

レートが分からない通貨のカテゴリがあると、その金額は総資産に含まれません。
「通貨・レート」画面でその通貨のレートを取得するか、手動で入力してください。
