記録した残高から、資産の増え方や偏りを分析できます。分析の多くは無料で使えます（プレミアムは年次レポートと、先月より前の月次レポートだけです）。

| 機能 | 場所 |
| --- | --- |
| 預け入れと値動き・成績表・リスクとリターン | 「チャート」タブのグラフの種類 |
| 目標までの予測 | 「チャート」タブ |
| 為替の影響 | 外貨などの資産の記録一覧 |
| 目標の配分・分散度・流動性・診断 | 「資産構成」タブ |
| 月次・年次レポート | 「設定」→「月次・年次レポート」 |
| アラート | ダッシュボードの「お知らせ」、「設定」→「アラート」 |

> **ご注意**
> 分析・予測・試算の結果は、記録と初期値から計算した**目安**です。将来の運用成果を保証するものではなく、特定の資産の売買をすすめるものでもありません。

## チャートの分析

「チャート」タブのグラフの種類で、次の3つを選べます（→ [チャートで推移を見る](chart)）。

### 預け入れと値動き

期間中の増減を、**預け入れ**（入金）・**引き出し**・**値動き**に分けて表示します。「自分で入れたお金」と「運用で増えた（減った）お金」を分けて確かめられます。

- 「預金・現金」カテゴリの資産と負債の増減は預け入れ・引き出し、ほかの資産の増減は値動きとして自動で分けます。
- 証券口座の現金のように、投資の資産と同じ金融機関（資産名の「（」より前が同じ）にある現金は、投資側として扱います。口座の中の売買は相殺され、配当や手数料は値動きに入ります。
- 証券口座への入金は、資産の編集画面の「毎月の積立額」を設定するか、記録にサブカテゴリ「入金」「出金」を付けると、預け入れ・引き出しとして分けられます。
- 「値動きの率（期間・目安）」「値動きの率（年・目安）」も表示します。
- 預け入れ・引き出しには、登録している口座どうしの移動（オートスイープなど）も含まれます。

### 成績表

資産ごとに、期間中に**増えた額・率・寄与度**を一覧にします。「増えた額」「率」「寄与度」で並べ替えられます。

- 率は預け入れを含みます。預け入れ・引き出しのある資産は、「値動きだけ」の率も表示します。
- 寄与度は、期間の始めの総資産に対する、増えた額の割合です。

### リスクとリターン

資産ごとの「1年の増え方」（縦）と「値動きの大きさ」（横）を、点の散布図で表示します。点の大きさは金額で、左上ほど「値動きが小さく、よく増えた」資産です。

- 1年以上の期間を選ぶと表示します。
- 選んだ期間の記録がそろった資産だけが対象です。積立額も「入金」「出金」の印もない資産は、買い増しと値上がりを区別できないため表示しません。

## 目標までの予測

資産目標を設定している場合、「チャート」タブで「目標までの予測」をオンにすると、総資産の推移の先に予測の線（点線と幅）を表示します。

- 予測は、総資産の実際の増え方をもとに計算します。3か月以上の記録が必要です。
- グラフの下の「目標までの軌道（年利ごと）」に、今のペースのままの場合と、年利0%・3%・5%・7%・10%で増えた場合に、目標に届く時期と残りの期間が表示されます。
- ダッシュボードの「資産目標」パネルにも、到達の見込みが表示されます。

## 為替の影響

外貨・金・暗号資産などの資産の記録一覧には、「為替の影響」が表示されます。期間（1か月・3か月・1年・全期間）中の増減を、**現地の値動き**と**為替の動き**に分けて確かめられます。

ポイント・マイルなどのカスタム通貨は、レートを自分で決めているため対象外です。月次レポートと成績表には、為替の影響の合計も表示されます。

## 資産構成の分析

「資産構成」タブの表示の切り替え（3列×2段）で、「円グラフ」「ツリーマップ」のほかに次の4つを選べます。分析の表示では、日付の切り替えと資産比率の一覧は表示されません。

### 目標の配分

理想の配分（例: 株60%・現金30%・金10%）を決めると、今の配分との差が分かります。

1. 「目標の配分を設定」をタップします。
2. 資産（カテゴリ）ごとの割合を、合計が100%になるように入力します。負債は配分に含めません。
3. 「許容範囲」（±○ポイント）を選んで保存します。

配分は、資産構成で選んでいる表示（資産別・カテゴリ別）ごとに決めます。各項目に「今 ○% ／ 目標 ○%」と、許容範囲に入っているかが表示されます。

### 分散度

カテゴリ・通貨・資産のそれぞれについて、割合の偏り（集中度）から分散度を点数で表示します。1つに集中している場合は、その名前と割合を表示します。点数は目安で、良し悪しを決めるものではありません。

### 流動性

資産を「すぐ使える」「数日で現金に」「すぐには使えない」の3段階に分け、割合をドーナツのグラフと段階ごとのカードで表示します。

- 段階は資産のカテゴリから決まります。資産の編集画面の「流動性」で変えられます。
- 「毎月の生活費」を設定すると、すぐ使えるお金が生活費の何か月分かが分かります（未設定の時は、取り崩しシミュレーターの毎月の取り崩し額を使います）。

### 診断

ポートフォリオ（資産の組み合わせ）を、2つの面から診断します。

- **効率性** … 今の配分を、同じリスクで期待リターンが最も高い組み合わせ（効率的フロンティア）と比べます。「効率的」「改善の余地あり」と、どの資産の割合を増やすと効率が良くなるかを表示します。
- **リバランス** … 「目標の配分」を保てているかを、月末ごとのずれで判定します（「保てています」「ときどきずれます」「ずれが続いています」）。6か月分以上の記録と、目標の配分の設定が必要です。

診断には、2種類以上の資産の種類（国内株式・外国株式・債券・現金・預金・金・不動産・REIT・その他）が必要です。「資産の種類を割り当てる」で、資産ごとの種類を確認・変更できます（初期値はカテゴリと通貨から決まります）。

## 月次・年次レポート

1か月（1年）の資産の動きを、グラフ中心のレポートにまとめます。「設定」→「月次・年次レポート」で開きます。月が変わると、ダッシュボードに「○月のレポートができました」と表示され、タップすると開けます。

- 「月次」「年次」を切り替え、見出しをタップして月・年を選びます。
- 総資産と前月比（前年比）、推移・増減のチャート、増加の内訳、増えた・減った資産、資産目標の達成率などを表示します。
- 目のボタンで金額を隠せます。「画像で共有」で、レポートを画像として共有できます。
- **年次レポートと、先月より前の月次レポートはプレミアム機能**です。

## アラート

条件に当てはまると、アプリを開いた時にダッシュボードの一番上に「お知らせ」を表示します。はじめはオフです。「設定」→「アラート」で、使う条件を選びます。

| 条件 | 内容 |
| --- | --- |
| 大きく減った時（前月比） | 資産や総資産が、前月より設定した割合以上減った時 |
| 目標の配分の許容範囲を超えた時 | 目標の配分から、許容範囲以上ずれた時 |
| 記録の入れ忘れ | 設定した日数以上、記録していない資産がある時 |
| 資産目標を達成した時 | 総資産が資産目標に届いた時 |
| 節目を超えた時 | 総資産が、設定した金額ごとの節目を超えた時 |

お知らせは「閉じる」で消せます。
