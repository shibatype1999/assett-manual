# データ移行（スクリーンショット・CSV）
<!-- position: 10 -->
<!-- description: 銀行・証券アプリのスクリーンショットや、Excel・Numbers などの CSV ファイルから、資産と残高をまとめて取り込む方法を説明します。 -->

ほかのアプリや表計算ソフトで管理していた資産と残高を、まとめて取り込めます。
「設定」→「データ移行」で、取り込み方を選びます。

| 取り込み方 | 内容 |
| --- | --- |
| スクリーンショットから | 銀行・証券・ポイントのアプリの残高画面のスクリーンショットから、資産名と金額を読み取ります。 |
| CSVファイルから | Excel・Numbers・家計簿アプリなどから書き出した CSV ファイルを取り込みます。過去の記録もまとめて移せます。 |

読み取りは、すべてお使いの端末の中で行います。画像やファイルの内容が外部に送られることはありません。

![データ移行](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/data-import.png)

> **ポイント**
> 取り込む前に、その時点のデータが自動でローカルバックアップされます。取り込んだ直後なら、完了画面の「取り込みを元に戻す」で取り込む前の状態に戻せます。

## スクリーンショットから取り込む

### 1. スクリーンショットを撮る

1. 銀行・証券・ポイントのアプリで、資産名と金額が並んだ残高の画面を表示します。
2. サイドボタンと音量を上げるボタンを同時に押して、スクリーンショットを撮ります。画面が長い場合は、何枚かに分けて撮ります。

**うまく読み取るコツ**

- 残高を隠す設定（＊＊＊）はオフにします。
- 資産名と金額が同じ行に見える画面を選びます。
- お知らせやポップアップは閉じてから撮ります。
- 「○月○日現在」が写っていれば、その日付で記録されます。

「データ移行」画面の「スクショの撮り方」で、読み取れる画面・読み取れない画面の見本を確認できます。

### 2. 読み取る

1. 「設定」→「データ移行」→「スクリーンショットから」をタップします。
2. はじめて使うときは、写真へのアクセスの許可を求められます。許可してください。
3. 撮ったスクリーンショットをまとめて選びます。
4. 読み取りが終わると、「取り込み内容の確認」画面が開きます。

### 3. 確認して登録する

「取り込み内容の確認」画面の操作は、CSV の場合と共通です（→ 下の「取り込み内容を確認して登録する」）。

### 取り込んだスクリーンショットの削除

登録が終わると、取り込んだスクリーンショットは**写真から自動で削除**されます。

- 削除の前に iOS の確認が表示されます。
- 削除したスクリーンショットは、写真アプリの「最近削除した項目」から30日間は元に戻せます。
- 写真へのアクセスを「選択した写真のみ」にしている場合などは、削除できないことがあります。その場合は、写真へのフルアクセスを許可するか、写真アプリで削除してください。

## CSV ファイルから取り込む

### 1. CSV ファイルを用意する

1行目は見出しにします。並び方は次の2通りのどちらでも取り込めます。

**A. 縦に並べる（おすすめ）** … 1行に1つの記録です。日付・資産名・金額は必須で、通貨・サブカテゴリ・メモは省略できます。

| 日付 | 資産名 | 金額 | 通貨 | サブカテゴリ | メモ |
| --- | --- | --- | --- | --- | --- |
| 2026/09/30 | A銀行 | 1,250,000 | JPY | 月末 | |
| 2026/09/30 | B証券 | 3,500 | USD | | |
| 2026/09/30 | 住宅ローン | -18,000,000 | | | |

**B. 横に並べる** … 1行に1つの日付で、2列目から資産ごとの列にします。家計簿の推移表と同じ形です。

| 日付 | A銀行 | B証券 | 住宅ローン |
| --- | --- | --- | --- |
| 2026/08/31 | 1,200,000 | 3,400 | -18,100,000 |
| 2026/09/30 | 1,250,000 | 3,500 | -18,000,000 |

**書き方のルール**

- 日付: 2026/09/30、2026-09-30、2026年9月30日 など
- 金額: カンマ・円・¥ が付いていてもかまいません。負債はマイナス（-、▲）で書きます。
- 通貨: JPY・USD などの通貨コードです。空欄の場合は、資産の通貨になります。
- 資産名: アプリにない名前は、新しい資産として作れます。
- 文字コード: UTF-8 と Shift_JIS（Excel）のどちらでも読み込めます。
- ファイルの大きさは 5MB までです。

「データ移行」画面の「CSVのひな形を書き出す」で、見出しの入ったひな形を書き出せます。資産を登録済みの場合は「ひな形を書き出す（今の資産入り）」で、今の資産名が入ったひな形になります。

**Excel・Numbers で保存するには**

- Excel: ファイル → 名前を付けて保存 → 「CSV UTF-8」
- Numbers: ファイル → 書き出す → CSV

保存したファイルは、「ファイル」アプリやメールで iPhone に送ります。

### 2. 列を割り当てる

1. 「設定」→「データ移行」→「CSVファイルから」をタップし、CSV ファイルを選びます。
2. 「CSVの読み込み」画面で、並び方（「縦に並べた形」「横に並べた形」）を確認します。自動で判定されますが、違う場合は切り替えます。
3. 「列の割り当て」で、各列が「日付」「資産名」「金額」「通貨」「サブカテゴリ」「メモ」「使わない」のどれかを確認します。見出しから自動で割り当てられます。
4. 「プレビュー（先頭3件）」で読み取り結果を確認し、「次へ（○件を確認）」をタップします。

## 取り込み内容を確認して登録する

「取り込み内容の確認」画面には、読み取った名前ごとに、登録先と金額（件数）が表示されます。

![取り込み内容の確認](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/data-import-review.png)

1. 名前ごとの登録先を確認します。
   - **既存** … アプリにある資産に記録します。
   - **新規** … 新しい資産を作って記録します。アイコン・通貨・カテゴリは、名前から自動で提案されます。記録がすべてマイナスの資産（ローンなど）は、負債として作られます。
   - 行をタップすると、登録先を「今ある資産」「新しい資産「○○」を作る」「登録しない」から選び直せます。
2. 金額を読み取れなかった行は「未入力」と表示されます。金額を入力しない場合は登録されません。
3. スクリーンショットの場合は、記録の日付を確認します。CSV で日付のない記録には、「日付の無い記録の日付」で選んだ日付が使われます。
4. 「同じ日付の記録がある時」で、すでに同じ日付の記録がある場合に「上書き」するか「スキップ」するかを選びます。
5. 「○件を登録」をタップします。

登録が終わると「取り込み完了」画面が表示されます。

- 読み取った名前と資産の結び付けは記憶され、次回からは自動で同じ資産に割り当てられます。
- 「続けて取り込む」で、ほかのスクリーンショットやファイルを続けて取り込めます。
- 「取り込みを元に戻す」で、取り込む前の状態に戻せます。

> **ご注意**
> 読み取った資産名や金額は、誤っている場合があります。登録する前に、必ず内容を確認してください。
