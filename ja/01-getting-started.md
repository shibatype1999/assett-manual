# はじめに

## 画面構成

画面下部のタブで、5つの画面を切り替えます。

![画面下部のタブ](../images/ja/tab-bar.png)

| タブ | できること |
| --- | --- |
| 入力 | 総資産とカテゴリごとの残高を確認し、残高を記録します。 |
| チャート | 総資産やカテゴリごとの推移をグラフと表で確認します。 |
| 資産構成 | 指定した日付時点の資産の内訳を確認します。 |
| カテゴリ | カテゴリの追加・編集・並べ替え・削除を行います。 |
| 設定 | 資産目標、通貨、バックアップ、表示などを設定します。 |

## 基本的な考え方

このアプリでは、お金の出入り（収入・支出）ではなく、**ある日時点の「残高」**を記録します。

- 資産の種類ごとに**カテゴリ**（例: 銀行、株、不動産）を作ります。
- カテゴリごとに、その日の**残高**を記録します。
- 各カテゴリの**最新の記録**が「現在の残高」になり、全カテゴリの合計が「総資産」になります。

たとえば、4月1日に銀行の残高を 100万円、5月1日に 120万円と記録すると、銀行の現在の残高は 120万円になります。
チャートでは、100万円から 120万円への推移として表示されます。

## はじめて使うときの流れ

はじめてアプリを起動すると、「銀行」「株」「不動産」の3つのカテゴリがあらかじめ用意されています。

1. **カテゴリを整える**
   「カテゴリ」タブで、必要なカテゴリを追加したり、使わないカテゴリを削除したりします。
   → [カテゴリを管理する](03-categories.md)
2. **残高を記録する**
   「入力」タブでカテゴリをタップし、現在の残高を記録します。
   → [残高を記録する](02-recording.md)
3. **目標を設定する（任意）**
   「設定」タブの「資産目標」で目標金額を入力すると、達成率が表示されます。
   → [設定](08-settings.md)
4. **定期的に記録する**
   月に1回など、決まったタイミングで残高を記録すると、チャートで推移を確認できます。
   → [チャートで推移を見る](04-chart.md)

> **ヒント**
> 大切なデータを失わないように、ときどきバックアップを取ることをおすすめします。
> → [データのバックアップと復元](07-backup.md)
