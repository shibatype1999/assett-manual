# データのバックアップと復元
<!-- position: 7 -->
<!-- description: データのバックアップ（ローカル・ファイル）と復元の方法を説明します。 -->

記録したデータは、すべてお使いの端末の中に保存されています。
機種変更や万一のトラブルに備えて、定期的にバックアップを取ることをおすすめします。

バックアップは「設定」タブ →「バックアップ」で行います。

![バックアップ画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/backup.png)

バックアップの方法は2種類あります。

| 方法 | 保存先 | 向いている用途 |
| --- | --- | --- |
| ローカルバックアップ | アプリの中 | 大きな変更をする前の一時的な保存 |
| データエクスポート | ファイル（iCloud Drive など） | 機種変更、長期的な保管 |

## ローカルバックアップ

アプリの中に、現在のデータのコピーを保存します。ファイルの共有は行いません。

### 保存する

1. 「ローカルバックアップ」をタップします。
2. 「バックアップを作成しました」と表示されたら完了です。ボタンの下に「最終バックアップ」の日時が表示されます。

保存できるローカルバックアップは1つだけです。もう一度保存すると、前回の内容は上書きされます。

### 復元する

1. 「ローカルから復元」をタップします。
2. 確認画面で「復元」をタップします。

> **ご注意**
> - 復元すると、現在のデータは上書きされます。
> - ローカルバックアップはアプリの中に保存されるため、**アプリを削除するとバックアップも消えます**。機種変更には、次の「データエクスポート」をお使いください。

## データエクスポート（ファイルに保存）

データを1つのファイル（`asset-年月日-時分秒.json`）として書き出し、iCloud Drive などに保存します。

### iOS の場合

1. 「データエクスポート」をタップします。
2. 共有シートが開きます。
3. 保存先を選びます。
   - **iCloud Drive に保存する場合** … 「"ファイル"に保存」をタップし、「iCloud Drive」内の保存したいフォルダを選んで「保存」をタップします。
   - **ほかのアプリに保存する場合** … Google Drive などのアプリを選び、画面の指示に従って保存します。

![共有シート](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/backup-share-sheet.png)

## データのインポート（ファイルから復元）

エクスポートしたファイルから、データを復元します。

### iOS の場合

1. 「データのインポート」をタップします。
2. ファイルの選択画面が開きます。エクスポートしたファイル（`asset-….json`）を選びます。
3. 確認画面で「復元」をタップします。
4. 「復元しました」と表示されたら完了です。

> **ご注意**
> - インポートすると、現在のデータは上書きされます。
> - このアプリでエクスポートしたファイル以外は読み込めません。読み込めない場合は「復元に失敗しました」と表示されます。

## バックアップに含まれるデータ

| 含まれるもの | 含まれないもの |
| --- | --- |
| カテゴリ | サブカテゴリの一覧（追加・変更した名前など） |
| 記録（残高・日付・メモなど） | 既定通貨 |
| 資産目標 | 表示形式（小数点桁数・端数処理） |
| 表示言語 | テーマ・テーマカラー |
| カスタム通貨 | |
| 通貨レートの設定 | |

バックアップに含まれない設定は、復元後に必要に応じて設定し直してください。
