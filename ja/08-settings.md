# 設定

「設定」タブでは、アプリのさまざまな設定を変更できます。

![設定タブ](../images/ja/settings.png)

| 項目 | 内容 |
| --- | --- |
| [資産目標](#資産目標) | 目標とする総資産の金額を設定します。 |
| [表示形式](#表示形式) | 小数点以下の桁数と端数処理を設定します。 |
| [テーマ](#テーマ) | ライト / ダーク表示を切り替えます。 |
| [テーマカラー](#テーマカラー) | アプリ全体の色を変更します。 |
| [サブカテゴリ管理](#サブカテゴリ管理) | 記録に付けるサブカテゴリを管理します。 |
| [言語](#言語) | アプリの表示言語を変更します。 |
| 通貨・レート | 既定通貨や為替レートを設定します。→ [通貨と為替レート](06-currency.md) |
| バックアップ | データのバックアップと復元を行います。→ [データのバックアップと復元](07-backup.md) |
| [ヘルプ](#ヘルプ) | ガイドやお問い合わせ先を開きます。 |
| [詳細](#詳細) | 利用規約やバージョンなどを確認します。 |

## 資産目標

目標とする総資産の金額を設定します。設定すると、「入力」タブに達成率と進捗バー、「チャート」タブの折れ線グラフに目標ラインが表示されます。

1. 「資産目標」をタップします。
2. 「通貨」を選び、「目標金額」を入力します。
3. 「保存」をタップします。

既定通貨以外の通貨で入力した場合は、既定通貨に換算して保存されます。

![資産目標の設定](../images/ja/settings-goal.png)

## 表示形式

金額の表示方法を設定します。

- **小数点桁数** … 「なし」「1」「2」から選びます。
- **端数処理** … 表示しない桁を「切り捨て」「四捨五入」「切り上げ」のどれで処理するかを選びます。

表示が変わるだけで、記録した金額そのものは変わりません。

## テーマ

画面の明るさを「端末の設定に従う」「ライト」「ダーク」から選びます。

## テーマカラー

アプリ全体の基調色を、8色から選びます。

## サブカテゴリ管理

記録に付けるサブカテゴリ（例: 給料、評価額）を管理します。

- **追加** … 右下の「＋」をタップし、名称を入力して「保存」をタップします。
- **名前の変更** … サブカテゴリをタップし、名称を変更して「保存」をタップします。
- **並べ替え** … 右側の「≡」を長押ししたまま、上下にドラッグします。
- **削除** … 右上の編集ボタン（鉛筆のアイコン）をタップし、ゴミ箱のアイコンをタップして、確認画面で「削除」をタップします。

サブカテゴリを削除しても、記録そのものは削除されません（その記録のサブカテゴリの表示がなくなります）。

## 言語

アプリの表示言語を選びます。「端末の設定に従う」を選ぶと、端末の言語設定に合わせて表示されます。

選べる言語: 日本語、English、한국어、简体中文、繁體中文、Español、Deutsch、Français、Русский、Bahasa Indonesia、Português、العربية、ไทย

最初から用意されているカテゴリ・サブカテゴリは、名前を変更していなければ、言語の切り替えに合わせて名前も切り替わります。

## ヘルプ

- **ガイド** … このご利用ガイドを開きます。
- **お問い合わせ** … お問い合わせ先を開きます。

## 詳細

- **プライバシーポリシー** / **利用規約** … それぞれのページを開きます。
- **ライセンス** … アプリで使用しているオープンソースソフトウェアのライセンスを表示します。
- **バージョン** … アプリのバージョンを表示します。
