# 通貨と為替レート
<!-- position: 8 -->
<!-- description: デフォルト通貨、為替レートの自動取得・手動設定、ポイント・マイルなどのカスタム通貨について説明します。 -->

このアプリでは、資産ごとに通貨を設定できます。総資産やグラフは、すべて**デフォルト通貨**に換算して表示されます。

通貨の設定は「設定」→「通貨・レート」で行います。

![通貨・レート画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/currency-settings.png)

## 使える通貨

| 種類 | 通貨 |
| --- | --- |
| 法定通貨 | 日本円、米ドル、ユーロ、英ポンド、豪ドル、カナダドル、スイスフラン、人民元、香港ドル、台湾ドル、韓国ウォン、インド・ルピー、インドネシア・ルピア、ブラジル・レアル、シンガポール・ドル、ニュージーランド・ドル、カタール・リヤル、サウジアラビア・リヤル、UAEディルハム、マレーシア・リンギット、タイ・バーツ、トルコ・リラ、ロシア・ルーブル |
| 金 | 金（g）、金（ozt） |
| 暗号資産 | ビットコイン、イーサリアム |
| カスタム通貨 | ポイント、マイル（最初から登録済み）と、ご自身で追加した通貨 |

金・暗号資産・ポイント・マイルは、金額ではなく**数量**（例: 10 g、0.5 BTC、3,000 pt）で記録します。

## デフォルト通貨を設定する

デフォルト通貨は、総資産・グラフ・資産目標を表示するときの通貨です。新しく追加する資産の通貨の初期値にもなります。

1. 「設定」→「通貨・レート」を開きます。
2. 「デフォルト通貨」の欄をタップします。
3. 回転式のピッカーで通貨を選び、「保存」をタップします。

「端末の設定に従う」を選ぶと、端末の言語に応じた通貨（日本語なら日本円、英語なら米ドルなど）が使われます。

> **ご注意**
> 記録がある状態でデフォルト通貨を変えると、確認の画面が表示されます。
> 記録ごとに保存した換算レート（後述）は変更前のデフォルト通貨へのレートのため、変更後は使えなくなります。過去の総資産やチャートは、取得できる過去のレートで換算し直すため、変更前と違う値になったり、正しく表示されなかったりする場合があります。

## 為替レートの自動取得

デフォルト通貨以外の通貨を使っている資産がある場合、アプリはインターネットから最新のレートを取得して換算します。

- アプリの起動時に、自動でレートを取得します。
- 「ダッシュボード」を下に引っ張ったときにも取得します。
- 自動での取得は**1日2回まで**です。上限に達した場合は「本日の更新回数の上限（1日2回）に達しています」と表示されます。
- 「通貨・レート」画面の「通貨レート設定」の右にある「レートを更新」で、使っている通貨のレートをまとめて取得し直せます。
- カスタム通貨（ポイント・マイルを含む）のレートは自動取得されません。手動で設定してください。
- インターネットに接続できない場合は、前回取得したレートや、アプリに内蔵された目安のレートが使われます。

### 過去のレート

チャートや資産構成で過去の日付の金額を表示するときは、**その日付のレート**で換算します。
過去のレートは、公開されている統計をもとにアプリに収録したものや、必要な期間だけ取得したものを使います。出典は「通貨・レート」画面の下に表示されます。
過去のレートがない通貨・期間では、記録ごとの換算レートや現在のレートで換算します。

ダッシュボードに「為替レート」パネルを追加すると、使用中の通貨のレートと最終更新日時を確認できます（→ [ダッシュボード](dashboard)）。

## 通貨レートを手動で設定する

「通貨・レート」画面の「通貨レート設定」には、資産で使っているデフォルト通貨以外の通貨が表示されます。

![通貨レート設定](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/currency-rate-row.png)

1. 「1 USD → JPY」のように表示された入力欄に、1単位あたりのデフォルト通貨の金額を入力します。
2. 右側の ✓ をタップして保存します。

最新のレートに戻したい場合は、見出しの右の「レートを更新」をタップします。取得に失敗した場合は、手動で入力してください。

カスタム通貨のレートは、その下の「カスタム通貨レート」で同じように設定します。

## 記録ごとの換算レート

外貨などの資産で残高を記録するときは、記録の画面に「換算レート」が表示され、**記録の日付のレート**が自動で入ります。

- 実際に両替したレートなどに書き換えると、そのレートは**その記録の日付の換算にだけ**使われます。「通貨・レート」の設定や、ほかの日付の換算には影響しません。
- 現在の総資産は、記録ごとのレートではなく、現在のレートで換算します。

→ [残高を記録する](recording)

## 金の評価

金（g・ozt）の資産がある場合は、「通貨レート設定」の下に「金の評価」が表示されます。金のレートは国際的なスポット価格のため、店頭の買取価格などに近づけたいときに使います。

| 項目 | 内容 |
| --- | --- |
| 日本の消費税（10%）を含める | ON にすると、日本の店頭価格と同じく、税込みの価格で評価します。 |
| 上乗せ率 | 販売店の手数料などを足すときに入力します（スポット価格 + ○%）。右側の ✓ で保存します。 |

設定すると、「評価に使う価格: 1 g = ○○円（スポット価格 × ○）」のように、実際に評価に使う価格が表示されます。

## カスタム通貨

一覧にない通貨や、ポイント・マイルなどを「カスタム通貨」として扱います。

- **ポイント**と**マイル**は最初から登録されています。削除はできませんが、名前・単位・レートは変更できます。はじめは「1 pt = 1円」「1 mi = 1円」として換算されるので、ご自身の価値の目安に合わせて変更してください。
- カスタム通貨は、資産の通貨として選べます。

### カスタム通貨を追加する

1. 「通貨・レート」画面の「カスタム通貨を追加」をタップします。
2. 次の項目を入力します。

   | 項目 | 説明 |
   | --- | --- |
   | 表示名 | 通貨の名前です。 |
   | 通貨コード | 通貨を区別するためのコードです（例: MYCOIN）。ほかの通貨と同じコードは使えません。追加後は変更できません。 |
   | 単位 | 金額のあとに表示する単位です（例: マイル）。空欄の場合は通貨コードが表示されます。 |
   | レート | 1単位あたりのデフォルト通貨の金額です。**必須**です（0より大きい数値）。 |

3. 「保存」をタップします。

### カスタム通貨を編集・並べ替え・削除する

- **編集** … 一覧の行をタップします。
- **並べ替え** … 右側の「≡」を長押ししたまま、上下にドラッグします。
- **削除** … 「カスタム通貨」の見出しの右にある鉛筆のアイコンをタップし、ゴミ箱のアイコンをタップして、確認画面で「削除」をタップします。

> **ご注意**
> 資産で使っているカスタム通貨は削除できません。削除しようとすると、使っている資産の名前が表示されます。先にそれらの資産の通貨を変更してください。

## 「一部の通貨のレートを取得できず、合計に反映されていません」と表示されたら

レートが分からない通貨の資産があると、その金額は総資産に含まれません。
「通貨・レート」画面でその通貨のレートを取得するか、手動で入力してください。
