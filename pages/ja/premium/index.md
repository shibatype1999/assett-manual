# プレミアム
<!-- position: 11 -->
<!-- description: プレミアム（サブスクリプション）で使える機能と、購入・解約の方法を説明します。 -->

資産管理アプリは無料で使えます。プレミアム（サブスクリプション）に加入すると、すべての機能を制限なく使えます。

![アップグレード画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/upgrade.png)

## プレミアムで使える機能

無料版の機能に加えて、次の機能が使えます。

| 機能 | 無料版 | プレミアム |
| --- | --- | --- |
| 資産の登録数 | 10個まで | 無制限 |
| チャートのグラフ | 折れ線グラフ | 折れ線・積み上げ・棒グラフ・増減要因 |
| チャートの期間 | 1ヶ月・3ヶ月・6ヶ月・1年 | 3年・5年・全期間・カスタムも選べる |
| ダッシュボード「総資産の推移」の期間 | 半年・1年 | 3年・5年・全期間も選べる |
| バックアップ | ローカルバックアップ・最新からの復元 | 自動バックアップ・一覧から選んで復元・データのインポート／エクスポート |
| 通貨 | 標準の通貨・ポイント・マイル | カスタム通貨の追加、ビットコイン・イーサリアム |

アプリ内でプレミアムの機能には鍵のアイコンが付いています。タップすると案内が表示され、「プランを見る」からアップグレード画面を開けます。

## プランと無料トライアル

「設定」→「アップグレード」で、「月払い」「年払い」のどちらかを選べます。料金はアップグレード画面に表示されます。

はじめて加入するときは、**14日間の無料トライアル**があります。

- 無料期間の終了後、選択したプランの料金が自動で請求されます。
- サブスクリプションは、現在の期間（無料期間を含む）が終了する24時間前までに解約しない限り、自動で更新されます。

## 加入する

1. 「設定」→「アップグレード」をタップします。
2. 「月払い」または「年払い」を選びます。
3. 「14日間無料で始める」をタップし、画面の指示に従って購入を完了します。

「プレミアムへようこそ！」と表示されたら完了です。承認待ちの場合は、承認されると自動でプレミアムが有効になります。

## 解約・プランの変更

解約やプランの変更は、App Store のアカウント設定から行います。
プレミアムをご利用中は、アップグレード画面の「サブスクリプションを管理」から開けます。

解約後や期限が切れた後は、無料版の機能に戻ります。記録したデータはそのまま残ります。

## 購入を復元する

機種変更やアプリの再インストールの後は、アップグレード画面の「購入を復元」をタップすると、加入中のプレミアムが再び有効になります。
