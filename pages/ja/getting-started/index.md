## 画面構成

画面下部のタブで、5つの画面を切り替えます。アプリを起動すると「ダッシュボード」が表示されます。

![画面下部のタブ](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/tab-bar.png)

| タブ | できること |
| --- | --- |
| ダッシュボード | 総資産・資産比率・前月比などのパネルを並べて確認します。 |
| 入力 | 資産ごとの残高を確認し、新しい残高を記録します。 |
| チャート | 総資産や資産・カテゴリごとの推移を、グラフと表で確認します。 |
| 資産構成 | 指定した日付時点の資産の内訳を確認します。 |
| 設定 | 資産目標、資産・カテゴリの管理、通貨、バックアップなどを設定します。 |

## 用語

このアプリでは、次の3つの言葉を使い分けています。

| 用語 | 意味 | 例 |
| --- | --- | --- |
| 資産 | 残高を記録する単位です。口座やお財布ごとに登録します。 | A銀行、B証券、現金、住宅ローン |
| カテゴリ | 似た分野の資産をまとめるグループです。1つの資産は1つのカテゴリに入れられます。 | 預金・現金、株式・投資信託、不動産 |
| サブカテゴリ | 記録1件ごとに付けるラベルです。残高が変わった理由を記録できます。 | 給料、売却、評価額 |

たとえば「A銀行」と「B銀行」の2つの資産を「預金・現金」カテゴリに入れると、チャートなどで銀行ごとの金額と、預金・現金の合計の両方を確認できます。

## 基本的な考え方

このアプリでは、お金の出入り（収入・支出）ではなく、**ある日時点の「残高」**を記録します。

- 各資産の**最新の記録**が「現在の残高」になり、全資産の合計が「総資産」になります。
- たとえば、4月1日にA銀行の残高を 100万円、5月1日に 120万円と記録すると、A銀行の現在の残高は 120万円になります。チャートでは、100万円から 120万円への推移として表示されます。

## はじめて使うときの流れ

はじめてアプリを起動すると、「銀行」「株」「不動産」の3つの資産と、「預金・現金」「株式・投資信託」などの標準のカテゴリがあらかじめ用意されています。

1. **資産を整える**
   「入力」タブ右下の「資産追加」で、お持ちの口座などを資産として追加します。使わない資産は削除できます。
   → [資産を管理する](assets)
2. **残高を記録する**
   「入力」タブで資産をタップし、「新規登録」から現在の残高を記録します。
   → [残高を記録する](recording)
3. **カテゴリを確認する（任意）**
   資産の編集画面、または「設定」→「カテゴリ」で、資産をカテゴリに入れます。
   → [カテゴリでまとめる](categories)
4. **目標を設定する（任意）**
   「設定」→「資産目標」で目標金額を入力すると、達成率や達成見込みが表示されます。
   → [設定](settings)
5. **定期的に記録する**
   月に1回など、決まったタイミングで残高を記録すると、チャートで推移を確認できます。
   → [チャートで推移を見る](chart)
