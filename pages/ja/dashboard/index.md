# ダッシュボード
<!-- position: 2 -->
<!-- description: 総資産や資産比率などのパネルを並べて表示するダッシュボードの使いかたを説明します。 -->

「ダッシュボード」タブでは、総資産や資産比率などを「パネル」として並べて表示します。アプリを起動すると最初に表示される画面です。

![ダッシュボード](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/dashboard.png)

金額は、すべて**デフォルト通貨**（→ [通貨と為替レート](currency)）に換算して表示されます。

## 為替レートを更新する

ダッシュボードを**下に引っ張る**と、為替レートや相場を最新の状態に更新します（1日2回まで）。

## 表示できるパネル

はじめは「総資産額」「資産比率」「資産別の総額」の3つが表示されています。次のパネルを追加できます。

| パネル | 内容 |
| --- | --- |
| 総資産額 | 総資産と前月比を表示します。複数の通貨を使っている場合は通貨ごとの小計、資産目標を設定している場合は達成率も表示します。 |
| 総資産額（シンプル） | 総資産額を大きな文字で表示し、その下に前月比を表示します。 |
| 資産比率 | 各資産の割合を円グラフで表示します。 |
| 総資産の推移 | 総資産の推移を折れ線グラフで表示します。期間は「半年」「1年」「3年」「5年」「全期間」から選べます。 |
| 資産別の総額 | 資産ごとの金額を大きい順に、割合のバー付きで表示します。多い場合は上位10件を表示し、残りは「すべて表示」で開きます。 |
| 前月比・前年比 | 総資産の、1か月前・1年前との差を表示します。 |
| 今月の増減が大きい資産 | 今月増えた資産・減った資産を、それぞれ上位3件まで表示します。 |
| 資産目標 | 目標金額・達成率・目標までの残り・直近6か月の月平均の増加額と、そのペースで続けた場合の達成見込み（年月）を表示します。 |
| 通貨別の内訳 | 通貨ごとの小計と、デフォルト通貨に換算した金額を表示します。 |
| 資産と負債 | 資産の合計・負債の合計と、その差額（純資産）を表示します。 |
| 為替レート | 資産で使っている外貨・カスタム通貨の「1単位あたりのデフォルト通貨の金額」と、最終更新日時を表示します。 |

> **ポイント**
> - 「前月比」は、1か月前の同じ日の総資産との比較です。
> - 「総資産の推移」の「3年」「5年」「全期間」は、プレミアム機能です（→ [プレミアム](premium)）。

### 資産別／カテゴリ別の切り替え

「資産比率」「資産別の総額」パネルの右上にある「資産別」「カテゴリ別」のボタンで、資産ごとの表示と、カテゴリごとにまとめた表示を切り替えられます。切り替えはパネルごとに保存されます。
このボタンは、資産の入ったカテゴリがあるときだけ表示されます（→ [カテゴリでまとめる](categories)）。

## パネルを追加・並べ替え・削除する

1. 右上の編集ボタン（鉛筆のアイコン）をタップします。
2. 次の操作ができます。
   - **並べ替え** … パネルの右側にある「≡」を長押ししたまま、上下にドラッグします。
   - **削除** … 「－」（赤い丸のアイコン）をタップします。
   - **追加** … 画面下部の「パネルを追加」をタップし、追加したいパネルを選びます。
   - **見た目の変更** … パレットのアイコンをタップします（次の項目を参照）。
3. 終わったら、右上の完了ボタン（✓）をタップします。

![ダッシュボードの編集](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/dashboard-edit.png)

## パネルの見た目を変更する

編集モードでパレットのアイコンをタップすると、そのパネルの見た目を変更できます。選ぶとすぐに反映されます。

- **背景色** … 一覧から選びます。左端はテーマカラーに合わせた標準の色です。
- **文字の大きさ** … 「小」「標準」「大」から選びます。
