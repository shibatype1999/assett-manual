# データのバックアップと復元
<!-- position: 9 -->
<!-- description: ローカルバックアップ・自動バックアップ・ファイルへのエクスポートと、データの復元方法を説明します。 -->

記録したデータは、すべてお使いの端末の中に保存されています。
機種変更や万一のトラブルに備えて、定期的にバックアップを取ることをおすすめします。

バックアップは「設定」→「バックアップ」で行います。

![バックアップ画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/backup.png)

| 方法 | 保存先 | 向いている用途 |
| --- | --- | --- |
| ローカルバックアップ | アプリの中 | 大きな変更をする前の一時的な保存 |
| 自動バックアップ（プレミアム） | アプリの中 | 定期的な保存 |
| データのエクスポート（プレミアム） | ファイル（iCloud Drive など） | 機種変更、長期的な保管 |

## ローカルバックアップ

アプリの中に、現在のデータのコピーを保存します。ファイルの共有は行いません。

### 保存する

1. 「ローカルバックアップ」をタップします。
2. 「バックアップを作成しました」と表示されたら完了です。ボタンの下に「最終バックアップ」の日時が表示されます。

ローカルバックアップは、保存するたびに1件ずつ追加されます。

### 最新のバックアップから復元する

1. 「ローカルから復元」をタップします。
2. 確認画面に最新のバックアップの日時が表示されます。「復元」をタップします。

### バックアップ一覧から選んで復元する（プレミアム機能）

1. 「バックアップ一覧から復元」をタップします。
2. 保存されているバックアップが、日時・「自動」「手動」の区別・資産と記録の件数とともに一覧表示されます。
3. 復元したいバックアップをタップし、確認画面で「復元」をタップします。

不要なバックアップは、一覧のゴミ箱のアイコンから削除できます。

![バックアップ一覧](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/backup-list.png)

> **ご注意**
> - 復元すると、現在のデータは上書きされます。
> - ローカルバックアップ（自動バックアップを含む）はアプリの中に保存されるため、**アプリを削除するとバックアップも消えます**。機種変更には「データのエクスポート」をお使いください。

## 自動バックアップ（プレミアム機能）

決まった間隔で、ローカルバックアップを自動で作成します。

1. 「自動バックアップ」をタップします。
2. 「自動バックアップを有効にする」を ON にします。ON にした時点で最初の1件が作成されます。
3. 「間隔」を「毎日」「毎週」「毎月」から選びます。
4. 「古い自動バックアップの削除」で、古いものを自動で削除する条件を選びます。

![自動バックアップ](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/auto-backup.png)

### 作成されるタイミング

自動バックアップは、決まった時刻には実行されません。**アプリを起動したとき（またはアプリに戻ったとき）**に、前回の自動バックアップから設定した間隔が過ぎていれば作成されます。

| 間隔 | 作成されるタイミング |
| --- | --- |
| 毎日 | 前回から24時間たった後、最初にアプリを起動したとき（例: 前回が14:30なら、翌日14:30以降の起動時） |
| 毎週 | 前回から7日たった後、最初にアプリを起動したとき |
| 毎月 | 前回の翌月の同じ日・同じ時刻を過ぎた後、最初にアプリを起動したとき。翌月に同じ日がない場合は月末日（例: 1/31 → 2/28） |

画面には、前回の自動バックアップの日時と、次回の予定が表示されます。

### 古い自動バックアップの削除

次のどれかを選べます。

- 削除しない
- ○日より前を削除（30日・90日・180日）
- 最新○件を残して削除（10件・20件・30件）
- 合計○MBを超えたら古い順に削除（10MB・50MB・100MB）

自動で削除されるのは**自動バックアップだけ**で、手動で作成したバックアップは削除されません。
「削除しない」を選ぶと保存容量が増え続けるため、必要に応じて一覧から不要なものを削除してください。画面には、自動バックアップの合計サイズと件数が表示されます。

## データのエクスポート（プレミアム機能）

データを1つのファイル（`asset-年月日-時分秒.json`）として書き出し、iCloud Drive などに保存します。

### iOS の場合

1. 「データのエクスポート」をタップします。
2. 共有シートが開きます。
3. 保存先を選びます。
   - **iCloud Drive に保存する場合** … 「"ファイル"に保存」をタップし、「iCloud Drive」内の保存したいフォルダを選んで「保存」をタップします。
   - **ほかのアプリに保存する場合** … Google Drive などのアプリを選び、画面の指示に従って保存します。

![共有シート](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/backup-share-sheet.png)

## データのインポート（プレミアム機能）

エクスポートしたファイルから、データを復元します。

### iOS の場合

1. 「データのインポート」をタップします。
2. ファイルの選択画面が開きます。エクスポートしたファイル（`asset-….json`）を選びます。
3. 確認画面で「復元」をタップします。
4. 「復元しました」と表示されたら完了です。

> **ご注意**
> - インポートすると、現在のデータは上書きされます。
> - このアプリでエクスポートしたファイル以外は読み込めません。読み込めない場合は「復元に失敗しました」と表示されます。

## バックアップに含まれるデータ

| 含まれるもの | 含まれないもの |
| --- | --- |
| 資産 | デフォルト通貨 |
| 記録（残高・日時・サブカテゴリ・メモ） | 表示形式・日付の書式 |
| カテゴリ | テーマ・テーマカラー |
| サブカテゴリ | ダッシュボードのパネルの構成 |
| 資産目標 | 自動バックアップの設定 |
| 表示言語 | |
| カスタム通貨 | |
| 通貨レートの設定 | |

バックアップに含まれない設定は、復元後に必要に応じて設定し直してください。
