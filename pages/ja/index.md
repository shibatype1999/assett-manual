# 資産管理アプリ ご利用ガイド
<!-- position: 1 -->
<!-- description: 資産管理アプリの使いかたをまとめたご利用ガイドです。 -->

資産管理アプリは、銀行預金・株式・不動産・暗号資産・ポイントなど、さまざまな資産の残高をひとつにまとめて記録し、総資産の推移をグラフで確認できるアプリです。

![ダッシュボード](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/dashboard.png)

## このアプリでできること

- **総資産をひと目で確認** … ダッシュボードに、総資産・資産比率・前月比などを好きな順に並べて表示できます。
- **資産ごとに残高を記録** … 銀行口座や証券口座などを「資産」として登録し、日付ごとの残高を記録します。
- **カテゴリでまとめて表示** … 似た資産を「カテゴリ」（例: 預金・現金、株式・投資信託）にまとめ、カテゴリ単位のグラフも表示できます。
- **複数の通貨に対応** … 外貨・金・暗号資産なども、自動取得した為替レートで換算して合計します。
- **推移をグラフで確認** … 折れ線グラフ・積み上げグラフ・棒グラフ、増減要因のグラフで資産の変化を確認できます。
- **過去の資産構成を確認** … 日付を指定して、その時点の内訳を円グラフやツリーマップで確認できます。
- **目標の管理** … 資産目標を設定すると、達成率や達成見込みが表示されます。
- **データのバックアップ** … 端末内への保存や自動バックアップのほか、iCloud Drive などにファイルとして保存できます。

記録したデータは、すべてお使いの端末の中に保存されます。アカウント登録は必要ありません。
