# カテゴリでまとめる
<!-- position: 5 -->
<!-- description: 似た分野の資産をカテゴリにまとめ、グラフなどをカテゴリ別に表示する方法を説明します。 -->

カテゴリは、似た分野の資産をまとめるグループです。
たとえば「A銀行」「B銀行」を「預金・現金」に、「C証券」「D証券」を「株式・投資信託」に入れると、チャート・資産構成・ダッシュボードを**カテゴリ別**に切り替えて、カテゴリごとの合計を確認できます。

カテゴリの管理は「設定」→「カテゴリ」で行います。

![カテゴリ画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/category-list.png)

一覧には、各カテゴリに入っている資産の名前が表示されます。

## 標準のカテゴリ

次のカテゴリが最初から用意されています。一覧では「標準」の印が付いています。

預金・現金、株式・投資信託、債券、保険、年金、ポイント、マイル、不動産、暗号資産、コモディティ（貴金属）、その他

- 標準のカテゴリは**削除できず、名前も変更できません**。名前はアプリの表示言語に合わせて表示されます。
- 色と、含める資産は変更できます。

## 資産をカテゴリに入れる

次のどちらの方法でも設定できます。

- **資産の画面から** … 資産の編集画面の「カテゴリ」で、入れたいカテゴリを選びます（→ [資産を管理する](assets)）。
- **カテゴリの画面から** … カテゴリをタップし、「含める資産」で入れたい資産にチェックを入れて「保存」をタップします。

1つの資産が入れるカテゴリは1つだけです。ほかのカテゴリに入っている資産には「現在: ○○」と表示され、チェックを入れるとこのカテゴリへ移ります。

## カテゴリを追加する

1. 「設定」→「カテゴリ」で、右下の「カテゴリ追加」をタップします。
2. 次の項目を設定します。

   | 項目 | 説明 |
   | --- | --- |
   | カテゴリ名 | カテゴリの名前です（例: 現金、証券）。 |
   | 色 | カテゴリ別に表示したときのグラフの色です。 |
   | 含める資産 | このカテゴリに入れる資産にチェックを入れます。 |

3. 右上の「保存」をタップします。

![カテゴリの編集画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/category-form.png)

## カテゴリを編集・並べ替え・削除する

- **編集** … カテゴリをタップし、内容を変更して「保存」をタップします。
- **並べ替え** … 右側の「≡」を長押ししたまま、上下にドラッグします。
- **削除** … カテゴリをタップし、編集画面の下にある「カテゴリを削除」をタップして、確認画面で「削除」をタップします。カテゴリを削除しても、**資産と記録は削除されません**。標準のカテゴリは削除できません。

## 資産別／カテゴリ別に表示を切り替える

次の画面では、「資産別」「カテゴリ別」のボタンで表示を切り替えられます。切り替えの設定は、画面（パネル）ごとに保存されます。

| 画面 | 切り替えの場所 |
| --- | --- |
| チャート | 画面上部 |
| 資産構成 | 総資産額の下 |
| ダッシュボード | 「資産比率」「資産別の総額」パネルの右上 |

「カテゴリ別」にすると、カテゴリに入っている資産はカテゴリごとの合計で表示され、どのカテゴリにも入っていない資産はそのまま資産として表示されます。

> **ポイント**
> 切り替えのボタンは、資産が1つ以上入っているカテゴリがあるときだけ表示されます。
