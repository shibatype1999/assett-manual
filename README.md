# 資産管理アプリ マニュアル

資産管理アプリ（開発リポジトリ: `assett`）の**利用者向け操作マニュアル**です。
各ページは Markdown で書かれており、CMS（Buldit）に取り込んでサイトとして公開することを想定しています。

- 対応OS: **iOS**（Android は今後追加予定）
- 対応言語: **日本語** / **英語**（ほかの言語は今後追加予定）

## フォルダ構成

```
assett-manual/
├── README.md            … このファイル（リポジトリの説明。サイトには載せない）
├── ja/                  … 日本語版
│   ├── index.md         … トップページ・目次
│   ├── 01-getting-started.md
│   ├── 02-recording.md
│   ├── 03-categories.md
│   ├── 04-chart.md
│   ├── 05-asset-composition.md
│   ├── 06-currency.md
│   ├── 07-backup.md
│   ├── 08-settings.md
│   └── 09-faq.md
├── en/                  … 英語版（ja/ と同じファイル名・同じ構成）
└── images/
    ├── README.md        … 必要なスクリーンショットの一覧（撮影リスト）
    ├── ja/              … 日本語UIのスクリーンショット
    └── en/              … 英語UIのスクリーンショット
```

## 執筆ルール

- **ファイル名は全言語で共通**にします。`ja/03-categories.md` の英語版は `en/03-categories.md` です。
- 各ページは `# 見出し1` を1つだけ持ち、それがページタイトルになります。
- アプリの画面上の文言（ボタン名・タブ名など）は「」（英語版は **太字**）で囲み、アプリ内の表記と一致させます。
- 画像は各言語フォルダから相対パスで参照します。
  例: `ja/02-recording.md` → `![残高の記録画面](../images/ja/record-form.png)`
- ページ間リンクも相対パスで書きます（例: `[カテゴリの管理](03-categories.md)`）。

## 画像（スクリーンショット）について

本文には画像の差し込み位置と、ファイル名がすでに入っています。
撮影が必要な画像の一覧と撮影時の条件は [images/README.md](images/README.md) にまとめています。
画像ファイルを所定の名前で `images/ja/`・`images/en/` に置けば、本文に表示されます。

## 言語を追加するには

1. `ja/` フォルダをコピーして、言語コード名のフォルダ（例: `ko/`、`zh-Hans/`）を作ります。
2. 各ファイルを翻訳します。ファイル名は変えません。
3. `images/<言語コード>/` を作り、その言語のUIで撮影したスクリーンショットを置きます。
4. 画像パス `../images/ja/` を `../images/<言語コード>/` に置き換えます。
5. 画面上の文言は、アプリ側の翻訳ファイル（`assett` リポジトリの `lib/l10n/app_<言語>.arb`）の表記に合わせます。

## Android 版を追加するには

操作の大部分は iOS と Android で共通です。OSによって操作が異なる箇所は、次のような見出しで書き分けます。

```markdown
### iOS の場合
…
### Android の場合
…
```

現在 OS ごとに違いが出るのは、主に次の箇所です。

- [データのバックアップと復元](ja/07-backup.md)（共有シート・ファイル選択画面）
- [よくある質問](ja/09-faq.md) の機種変更に関する項目

Android 用のスクリーンショットは `images/<言語>/android/` に分けて置くことを推奨します。

## CMS（Buldit）へ取り込むときの注意

- この `README.md` と `images/README.md` はリポジトリ管理用のため、サイトには取り込まないでください。
- 画像・ページ間リンクは相対パスで書いています。CMS 側で画像のURLやページのURLが変わる場合は、取り込み時にパスを置き換えてください。
- 利用規約・プライバシーポリシー・お問い合わせのURLは未確定のため、本文には入れていません。決まりしだい [ja/08-settings.md](ja/08-settings.md) の「詳細」「ヘルプ」の項に追記してください。
