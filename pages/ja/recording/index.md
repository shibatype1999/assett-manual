# 残高を記録する
<!-- position: 3 -->
<!-- description: 「入力」タブのシンプル・一括・資産別・カレンダーの4つの記録方法と、記録の編集・削除、記録一覧の見かたを説明します。 -->

残高の記録は「入力」タブ（画面タイトル「資産入力」）で行います。画面上部のタブで、4つの記録方法を切り替えられます。最後に使ったタブは、次に開いたときも選ばれた状態になります。

| タブ | 向いている使い方 |
| --- | --- |
| シンプル | 資産を選んで、1件ずつすばやく記録する |
| 一括 | よく一緒に記録する資産を、金額を入れるだけでまとめて記録する |
| 資産別 | 資産の一覧から選んで記録し、資産ごとの記録一覧を確認する |
| カレンダー | 記録した日をカレンダーで確認し、日付を選んで記録する |

![入力タブ](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/input.png)

> **ポイント**
> - 金額には、増えた分・減った分ではなく**その時点の残高**を入力します。
> - 金額は、「設定」→「表示形式」の数字の書式に関係なく、「1,234.56」の形（小数点はピリオド）で入力します。
> - 「負債として扱う」を ON にした資産では、金額をプラスで入力しても自動的にマイナス（負債）として記録されます。

## シンプル：1件ずつ記録する

1. 「シンプル」タブで、上部の「資産を選択」をタップし、記録する資産をアイコンの一覧から選びます。
   一覧の最後の「資産追加」から、新しい資産を追加してそのまま記録することもできます。
2. 日付・金額などを入力します（各項目は、下の「記録の入力項目」を参照）。
3. 「保存」をタップします。

「「○○」に記録しました」と表示されます。画面は閉じないので、資産を選び直して続けて記録できます（金額・メモ・サブカテゴリは空に戻り、日付はそのまま残ります）。

![シンプル入力](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/input-simple.png)

## 記録の入力項目

シンプル入力と「残高を記録」画面では、次の項目を入力します。

| 項目 | 説明 |
| --- | --- |
| 日付 | 残高を確認した日時です。タップすると、カレンダーで日付を選んだあと、続けて時刻を選べます。初期値は現在の日時です。 |
| 通貨 | 資産に設定した通貨が表示されます（ここでは変更できません）。 |
| 金額 | その日時点の残高を入力します。3桁ごとのカンマは自動で入ります。 |
| 換算レート | 資産の通貨がデフォルト通貨と違う場合だけ表示されます。記録の日付のレートが自動で入ります（後述）。 |
| サブカテゴリ（任意） | 回転式のピッカーで、記録の種類（例: 給料、評価額）を選べます。 |
| メモ（任意） | 自由にメモを残せます。改行して複数行で書けます。 |

キーボードは、余白をタップするか、キーボードの上の「完了」で閉じられます。

### 換算レートについて

外貨・金・暗号資産などの資産では、金額の下に「換算レート」（例: 1 USD = ○○ JPY）が表示されます。

- はじめは、**記録の日付のレート**が自動で入ります。日付や資産を変えると、そのレートに入れ替わります。
- 実際に両替したレートなどに書き換えることもできます。書き換えたレートは**この記録の換算にだけ**使われ、「通貨・レート」の設定は変わりません。
- 書き換えたレートは、入力欄の右の ↻ ボタンで自動のレートに戻せます。

→ [通貨と為替レート](currency)

## 一括：まとめて記録する

毎月の給料日や月末など、いつも同じ組み合わせで記録する資産を「一括入力」として登録しておくと、金額を入れるだけでまとめて記録できます。

![一括入力](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/input-batch.png)

### 一括入力を作る

1. 「一括」タブで「一括入力を作成」をタップします（「設定」→「一括入力」からも作れます）。
2. 次の項目を設定します。

   | 項目 | 説明 |
   | --- | --- |
   | 名前 | 一括入力の名前です（例: 月末の残高、給料日）。空欄の場合は「一括入力」になります。 |
   | サブカテゴリ（まとめて設定） | 記録に付けるサブカテゴリです。すべての資産に同じものが付きます。 |
   | 資産 | 「資産を追加」で、まとめて記録する資産を選びます。右側の「≡」をドラッグして並べ替えられます。 |

   資産ごとに違うサブカテゴリを付けたい場合は、資産の下のサブカテゴリをタップして変更します。
3. 右上の保存ボタンをタップします。

### 一括入力で記録する

1. 「一括」タブで、使う一括入力をタップします。
2. 「日付」を確認し、必要に応じて変更します。
3. 資産ごとに金額を入力します。入力欄には、前回の金額が「前回 ○○」と薄く表示されます。
   - 「空欄に前回の金額を入れる」をタップすると、まだ入力していない資産に前回の金額が入ります。変わらない資産があるときに便利です。
4. 「○件を登録」をタップします。

**空欄の資産は記録されません。** 入力した資産だけが、それぞれの資産の通貨で記録されます。

### 一括入力を編集・削除する

「一括」タブで一括入力を**長押し**するか、記録の画面右上の鉛筆のアイコンをタップすると、編集画面が開きます。
削除は、編集画面の下にある「この一括入力を削除」から行います。一括入力を削除しても、登録済みの記録は削除されません。

## 資産別：資産の一覧から記録する

「資産別」タブには、登録した資産が一覧で表示されます。

- 各資産には、**最新の残高**（その資産の通貨のまま）と、その下に**前月比**（1か月前との差と増減率）が表示されます。増えた場合は緑、減った場合は赤で表示されます。
- 総資産に含めない設定にした資産は、薄く表示されます（→ [資産を管理する](assets)）。
- 資産をタップすると、その資産の記録一覧が開きます。一覧の右下の「新規登録」をタップすると「残高を記録」画面が開き、その資産の記録を追加できます。
- 右下の「資産追加」で資産を追加できます。右上の鉛筆のアイコンで「資産一覧」を開き、資産の編集・並べ替え・削除ができます（→ [資産を管理する](assets)）。

![資産別](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/input-by-asset.png)

### 記録一覧の見かた

![記録一覧](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/asset-detail.png)

- 画面上部に「現在の残高」（最新の記録の金額）と、前月比が表示されます。
- 記録は「日付」「サブカテゴリ」「金額」「メモ」の表で表示されます。長いメモは省略されるため、全文は記録をタップして確認します。
- 次の方法で、表示する記録を絞り込んだり並べ替えたりできます。

| 操作 | 内容 |
| --- | --- |
| 期間 | 「1年」（初期値）「3年」「全期間」「カスタム」から選びます。「カスタム」では、開始日と終了日を回転式のピッカーで指定します。 |
| 並び順 | 「日付（新しい順）」「日付（古い順）」「金額（大きい順）」「金額（小さい順）」から選びます。 |
| 表示件数 | 1ページに表示する件数（30件・50件・100件）を選びます。 |

件数が多い場合は、表の下のページ番号や「‹」「›」でページを切り替えます。表の右上には、条件に合う記録の件数（「全○件」）が表示されます。

## カレンダー：記録した日を確認する

「カレンダー」タブでは、記録した日をカレンダーで確認し、日付を選んで記録を追加できます。

![カレンダー](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/input-calendar.png)

- 記録のある日には点が付きます。その日に総資産が**増えた日は緑、減った日は赤**です。
- 日付をタップすると、その日の記録（資産名・金額・前回の記録からの増減・メモ）が下に一覧表示されます。記録をタップすると編集できます。
- 「この日に記録を追加」をタップすると、選んだ日付で「残高を記録」画面が開きます。過去の日付にさかのぼって記録できます。
- 月は、左右の矢印か、カレンダーを横にスワイプして切り替えます。年月の表示をタップすると、年 → 月の順に選んで移動できます。
- 右側の絞り込みのアイコンで資産を選ぶと、その資産の記録だけを表示します（点の色も、その資産の増減になります）。
- カレンダーと一覧の間にある区切り線の中央のボタンで、カレンダーを閉じて一覧を広く表示できます。

## 記録を編集する

次のどこからでも、記録をタップすると「記録を編集」画面が開きます。内容を修正し、「保存」をタップします。

- 「資産別」タブで資産をタップした記録一覧
- 「カレンダー」タブの、日付ごとの記録の一覧

記録の編集では、資産は変更できません。

## 記録を削除する

1. 「資産別」タブで資産をタップし、記録一覧の右上にある編集ボタン（鉛筆のアイコン）をタップします。
2. 削除したい記録の右側にあるゴミ箱のアイコンをタップします。
3. 削除が終わったら、右上の完了ボタン（✓）をタップします。

> **ご注意**
> 記録の削除は、確認なしですぐに実行され、元に戻せません。

## サブカテゴリについて

サブカテゴリは、記録に付けるラベルです。はじめは「売却」「引き出し」「給料」「評価額」「預金」が用意されています。
サブカテゴリを付けておくと、チャートの「増減要因」で、残高が何によって増えたり減ったりしたかを確認できます（→ [チャートで推移を見る](chart)）。
サブカテゴリの追加・名前の変更・並べ替え・削除は、「設定」→「サブカテゴリ」で行います（→ [設定](settings)）。

## ほかのアプリから移す

銀行・証券アプリのスクリーンショットや、表計算ソフトの CSV ファイルから、まとめて記録を取り込むこともできます。
→ [データ移行（スクリーンショット・CSV）](data-import)
