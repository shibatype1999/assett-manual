# 資産を管理する
<!-- position: 4 -->
<!-- description: 資産の追加・編集・並べ替え・削除と、負債として扱う資産について説明します。 -->

「資産」は、残高を記録する単位です（例: A銀行、B証券、現金、住宅ローン）。口座やお財布ごとに登録します。

資産の管理は「資産一覧」画面で行います。「入力」タブ右上の鉛筆のアイコン、または「設定」→「資産一覧」から開きます。

![資産一覧](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/asset-list.png)

## 資産を追加する

1. 次のどれかから「資産追加」をタップします。
   - 「入力」タブの「資産別」の右下
   - 「資産一覧」画面の右下
   - 「シンプル」タブなどで資産を選ぶ一覧の最後
2. 「資産を追加」画面で、次の項目を設定します。

   | 項目 | 説明 |
   | --- | --- |
   | 資産名 | 資産の名前です（例: A銀行、B証券、現金）。 |
   | 資産の通貨 | この資産の記録で使う通貨を、回転式のピッカーで選びます。初期値はデフォルト通貨です。 |
   | カテゴリ | この資産を入れるカテゴリを選びます。入れない場合は「なし」を選びます。 |
   | 負債として扱う | ON にすると、この資産の金額はすべてマイナス（負債）として集計されます。 |
   | 色 | グラフなどで使う色を選びます。 |
   | アイコン | 資産のアイコンを選びます。 |

   資産名を入力すると、名前に合ったアイコン・通貨・カテゴリが「おすすめの設定」として表示されることがあります。「この設定にする」をタップすると、まとめて反映されます（→ [AI 機能](ai)）。
3. 右上の「保存」をタップします。

![資産を追加画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/asset-form.png)

> **ポイント**
> - デフォルト通貨以外の通貨を選んだ場合、その通貨のレートは「設定」→「通貨・レート」で確認・変更できます（→ [通貨と為替レート](currency)）。
> - ローンやクレジットカードの未払い残高などは、「負債として扱う」を ON にした資産で管理すると、総資産から差し引かれます。

## 資産をまとめて登録する

「資産一覧」画面の右上にあるきらきらのアイコン（まとめて登録）をタップすると、「A銀行の普通預金、B証券でNISA、純金積立」のように、持っている口座や資産をふだんの言葉で書くだけで、資産をまとめて登録できます。
→ [AI 機能（まとめて登録）](ai)

## 資産を編集する

「資産一覧」画面で、編集したい資産をタップします。「資産を編集」画面で内容を変更し、「保存」をタップします。

## 資産を並べ替える

「資産一覧」画面で、資産の右側にある「≡」を長押ししたまま、上下にドラッグします。
ここでの並び順は、「入力」タブやチャートなどの並び順にも反映されます。

## 資産を一時的に集計から外す

「資産一覧」画面で、資産の右側のスイッチ（総資産に含める）をオフにすると、その資産を総資産・チャート・資産構成などの集計から一時的に外せます。

- 外した資産には「集計から除外中」と表示され、「入力」タブなどでは薄く表示されます。
- 記録はそのまま残り、外している間も記録を追加できます。
- スイッチをオンに戻すと、再び集計に含まれます。

解約した口座や、しばらく様子を見たい資産を、削除せずに残しておきたいときに使います。

## 資産を削除する

複数の資産をまとめて削除できます。

1. 「資産一覧」画面の右上にある編集ボタン（鉛筆のアイコン）をタップします。
2. 削除したい資産の左側にあるチェックボックスにチェックを入れます。
3. 左下のゴミ箱のアイコンをタップします。
4. 確認画面で「削除」をタップします。
5. 右上の完了ボタン（✓）をタップして、編集モードを終わります。

> **ご注意**
> 資産を削除すると、その資産の**記録もすべて削除**され、元に戻せません。
> 必要に応じて、事前にバックアップを取ってください（→ [データのバックアップと復元](backup)）。

## 最初から用意されている資産について

はじめて起動したときは「銀行」「株」「不動産」の3つの資産が用意され、それぞれ「預金・現金」「株式・投資信託」「不動産」のカテゴリに入っています。
これらは自由に編集・削除できます。名前を変更していない場合、アプリの表示言語を切り替えると、資産名もその言語に切り替わります。
