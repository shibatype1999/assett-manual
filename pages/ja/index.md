# 資産管理アプリ ご利用ガイド
<!-- position: 1 -->
<!-- description: 資産管理アプリの使いかたをまとめたご利用ガイドです。 -->

資産管理アプリは、銀行預金・株式・不動産・仮想通貨・ポイントなど、さまざまな資産の残高をひとつにまとめて記録し、総資産の推移をグラフで確認できるアプリです。

![アプリのホーム画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/home.png)

## このアプリでできること

- **総資産をひと目で確認** … カテゴリごとの最新残高を合計し、総資産として表示します。
- **複数の通貨に対応** … 外貨・金・ビットコインなどの資産も、自動取得した為替レートで換算して合計します。
- **推移をグラフで確認** … 折れ線グラフ・積み上げグラフ・棒グラフで、資産の増減を確認できます。
- **過去の資産構成を確認** … 日付を指定して、その時点の資産の内訳を確認できます。
- **目標の管理** … 資産目標を設定すると、達成率が表示されます。
- **データのバックアップ** … 端末内への保存のほか、iCloud Drive などにファイルとして保存できます。

記録したデータは、すべてお使いの端末の中に保存されます。アカウント登録は必要ありません。
