# チャートで推移を見る
<!-- position: 6 -->
<!-- description: チャートで総資産や資産・カテゴリごとの推移と、増減要因を確認する方法を説明します。 -->

「チャート」タブでは、総資産や資産・カテゴリごとの残高の推移を、グラフと表で確認できます。

![チャートタブ](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/chart-line.png)

グラフの金額は、すべてデフォルト通貨に換算して表示されます。画面全体を上下にスクロールして確認します。

## 表示する対象と期間を選ぶ

画面上部の「資産」「期間」の枠の中を左右にスワイプして回し、**中央の枠に止まった項目**が選ばれます。見えている項目をタップして選ぶこともできます。

- **資産** … 「全体」を選ぶと総資産の推移、資産名を選ぶとその資産だけの推移を表示します。
- **期間** … 「1ヶ月」「3ヶ月」「6ヶ月」「1年」「3年」「5年」「全期間」「カスタム」から選びます。

「カスタム」を選ぶと、開始日と終了日を回転式のピッカーで指定できます。指定した期間はグラフの上に表示され、タップすると期間を変更できます。

> **ポイント**
> - カテゴリを使っている場合は、画面上部の「資産別」「カテゴリ別」で切り替えられます。「カテゴリ別」にすると、「資産」の枠が「カテゴリ」に変わり、カテゴリごとの推移を表示します（→ [カテゴリでまとめる](categories)）。
> - 「3年」「5年」「全期間」「カスタム」は、プレミアム機能です（鍵のアイコンが付いています）。

## グラフの種類を切り替える

グラフの下のボタンで、グラフの種類を切り替えます。

| 種類 | 内容 |
| --- | --- |
| 折れ線グラフ | 推移を1本の線で表示します。「全体」を選んでいて資産目標を設定している場合は、目標額の赤いラインも表示されます。 |
| 積み上げグラフ | 資産（カテゴリ）ごとの金額を積み重ねて「資産別推移」として表示します。負債はマイナス側に表示されます。 |
| 棒グラフ | 資産（カテゴリ）ごとの金額を積み上げた棒グラフで表示します。 |
| 増減要因 | 残高の増減を、記録に付けたサブカテゴリ別に集計して表示します（後述）。 |

- 「積み上げグラフ」「棒グラフ」は、「全体」を選んでいるときだけ使えます。
- 「折れ線グラフ」以外は、プレミアム機能です。
- グラフをタップすると、その時点の金額を確認できます。
- 「棒グラフ」「増減要因」では、凡例の項目をタップすると、その項目をグラフに表示／非表示できます。凡例の項目が多い場合は、上位だけが表示され、残りは＋ボタンで開きます。

![積み上げグラフ](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/chart-stacked.png)

## 増減要因を見る

「増減要因」では、各記録の「前回の記録からの増減額」を、その記録のサブカテゴリ別に集計します。たとえば、給料で増えた分と、評価額の変動で増えた分を分けて確認できます。

- **上段の棒グラフ** … 期間を月ごと（1か月以内の期間では日ごと）に区切り、増減額をサブカテゴリ別に色分けして積み上げます。増加は0より上、減少は0より下に表示されます。
- **下段の一覧（期間内の増減要因）** … 期間内の増減額をサブカテゴリごとに合計し、大きい順に並べます。

サブカテゴリを付けていない記録は「未分類」として集計されます。各資産の最初の記録は比較する前回の記録がないため、集計の対象外です。

![増減要因](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/chart-change-factors.png)

## 推移の表

「増減要因」以外では、グラフの下に日付・金額・増減額の表が表示されます。

- 「日」「月」「年」で集計の単位を切り替えられます。「月」「年」では、その期間の最後の金額が表示されます。
- 増減額は、ひとつ前の期間からの差額です。増えた場合は緑、減った場合は赤で表示されます。
- 列の見出しをタップすると、その列で並べ替えます。もう一度タップすると、昇順と降順が切り替わります。
- 「表示件数」で、1ページに表示する行数（30 / 50 / 100）を選べます。行数が多い場合は、表の下のページ番号で切り替えます。

![推移の表](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/chart-table.png)

> **グラフが表示されないときは**
> 選んだ期間に、グラフを描くのに必要な記録（2日分以上）がないと、「この期間に表示できる記録がありません」と表示されます。
> 期間を長くするか、別の日付の記録を追加してください。
