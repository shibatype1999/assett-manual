## 資産目標

目標とする総資産の金額を設定します。

1. 「資産目標」をタップします。
2. 「通貨」を選び、「目標金額」を入力します。
3. 必要に応じて「達成したい年」を選びます（今年から40年後まで。「指定しない」も選べます）。設定すると、ダッシュボードの「目標へのアドバイス」に、その年までに達成するための月あたりの金額の目安が表示されます。
4. 「保存」をタップします。

デフォルト通貨以外の通貨で入力した場合は、デフォルト通貨に換算して保存されます。

「チャートに目標額を表示する」を ON にすると、チャートの総資産のグラフに目標額の赤いラインが表示されます（初期値は ON）。このスイッチは、切り替えた時点で保存されます。

目標を設定すると、ダッシュボードの「総資産額」パネルに達成率が表示されます。「資産目標」パネルを追加すると、目標までの残りや達成見込みも確認できます（→ [ダッシュボード](dashboard)）。

![資産目標の設定](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/settings-goal.png)

## 表示形式

金額の表示方法を設定します。

- **小数点桁数** … 「なし」「1」「2」から選びます。
- **端数処理** … 表示しない桁を「切り捨て」「四捨五入」「切り上げ」のどれで処理するかを選びます。
- **数字の書式** … 桁区切りと小数点の記号を選びます。

  | 書式 | 例 |
  | --- | --- |
  | カンマ区切り | 1,234,567.89 |
  | 区切りなし | 1234567.89 |
  | ピリオド区切り（小数点はカンマ） | 1.234.567,89 |
  | スペース区切り（小数点はカンマ） | 1 234 567,89 |
  | アポストロフィ区切り | 1'234'567.89 |

表示が変わるだけで、記録した金額そのものは変わりません。
金額の入力欄は、どの書式を選んでも「1,234.56」の形で入力します。

## 日付の書式

アプリ内のすべての日付の表示方法を選びます。画面には、選んだ書式で今日の日付の例が表示されます。

選べる書式（2026年8月19日の場合）: 2026/08/19、19/8/26、8/19/26、8/19/2026、19/08/2026、19.08.2026、19-08-2026、2026/8/19、2026.08.19、2026-08-19

## スキン

アプリ全体のデザイン（色・角の丸み・文字）をまとめて変えられます。はじめは「シルク・サテン」が選ばれています。
それぞれのスキンには見本（タイトル部分・総資産・下のメニュー）が表示され、タップするとすぐに切り替わります。

| グループ | スキン |
| --- | --- |
| ベーシック | スタンダード、クール、キュート、ホット、アイス |
| ラグジュアリー | ブラックカード、ミッドナイト・ダイヤル、キルティング・レザー、クロコダイル、ゴールドバー、ダイヤモンド、シルク・サテン、ロイヤル・ゴールド、グリーン・ダイヤル、エメラルド・クロコ、エメラルド・カット、翡翠、抹茶・金箔、セージ・シルク |

「テーマ」と「テーマカラー」は、スキンが「スタンダード」のときだけ使えます。ほかのスキンでは「スタンダードのみ」と表示されます。

![スキン](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/settings-skin.png)

## テーマ

画面の明るさを「端末の設定に従う」「ライト」「ダーク」から選びます（スキンが「スタンダード」のときのみ）。

## テーマカラー

アプリ全体の基調色を選びます（スキンが「スタンダード」のときのみ）。色を選ぶと、画面下部の「プレビュー」で、総資産のパネルやボタン、下のメニューがどのように見えるかをすぐに確認できます。

## パスコードロック

アプリを開くときと、ほかのアプリからこのアプリに戻ったときに、パスコードの入力が必要になります。

1. 「設定」→「パスコードロック」をタップします。
2. 「パスコードロック」を ON にします。
3. 桁数（「4桁」「6桁」）を選び、新しいパスコードを入力します。
4. 確認のため、もう一度同じパスコードを入力します。

- パスコードを変えるときは「パスコードを変更」、やめるときは「パスコードロック」を OFF にします。どちらも、現在のパスコードの入力が必要です。
- 入力の失敗が続くと、しばらく入力できなくなります。

> **ご注意**
> パスコードを忘れるとアプリを開けなくなり、パスコードを元に戻す方法もありません。設定する前に、データのエクスポートでバックアップを取っておくことをおすすめします（→ [データのバックアップと復元](backup)）。

> **ヒント**
> Face ID でロックしたい場合は、ホーム画面でこのアプリのアイコンを長押しし、「Face IDを必要にする」を選ぶことをおすすめします（iOS 18 以降）。

## サブカテゴリ

記録に付けるサブカテゴリ（例: 給料、評価額）を管理します。

- **追加** … 右下の「＋」をタップし、名称を入力して「保存」をタップします。
- **名前の変更** … サブカテゴリをタップし、名称を変更して「保存」をタップします。
- **並べ替え** … 右側の「≡」を長押ししたまま、上下にドラッグします。
- **削除** … 右上の編集ボタン（鉛筆のアイコン）をタップし、ゴミ箱のアイコンをタップして、確認画面で「削除」をタップします。

サブカテゴリを削除しても、記録そのものは削除されません（その記録のサブカテゴリの表示がなくなります）。

## 言語

アプリの表示言語を選びます。「端末の設定に従う」を選ぶと、端末の言語設定に合わせて表示されます。

選べる言語: 日本語、English、한국어、简体中文、繁體中文、Español、Deutsch、Français、Русский、Bahasa Indonesia、Português、العربية、ไทย、Italiano

最初から用意されている資産・サブカテゴリは、名前を変更していなければ、言語の切り替えに合わせて名前も切り替わります。標準のカテゴリの名前も、表示言語に合わせて表示されます。

## ヘルプ

- **ガイド** … このご利用ガイドを開きます。
- **お問い合わせ** … お問い合わせの画面を開きます。「不具合」「その他」から種類を選んで「メールで問い合わせる」をタップすると、メールアプリが開きます。宛先・件名と、機種・OS・アプリのバージョンはあらかじめ入力されるので、内容を書いて送信してください。資産のデータは含まれません。メールアプリを開けない場合は、画面に表示される宛先のアドレスをコピーして、メールでお問い合わせください。

## 詳細

- **プライバシーポリシー** / **利用規約** … それぞれのページを開きます。
- **ライセンス** … アプリで使用しているオープンソースソフトウェアのライセンスを表示します。
- **バージョン** … アプリのバージョンを表示します。
