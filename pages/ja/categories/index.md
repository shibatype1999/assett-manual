# カテゴリを管理する
<!-- position: 3 -->
<!-- description: カテゴリの追加・編集・並べ替え・削除と、負債カテゴリについて説明します。 -->

カテゴリは、資産の種類ごとのまとまりです（例: 銀行、株、不動産、仮想通貨、クレジットカード）。
カテゴリの管理は「カテゴリ」タブで行います。

![カテゴリタブ](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/category-list.png)

## カテゴリを追加する

1. 「カテゴリ」タブで、右下の「＋」ボタンをタップします。
2. 「カテゴリを追加」画面で、次の項目を設定します。

   | 項目 | 説明 |
   | --- | --- |
   | カテゴリ名 | カテゴリの名前です（例: 仮想通貨、現金、車）。 |
   | カテゴリの通貨 | このカテゴリの記録で使う通貨です。外貨・金・ビットコイン・ポイントなども選べます。 |
   | 負債として扱う | ON にすると、このカテゴリの金額はすべてマイナス（負債）として集計されます。 |
   | 色 | グラフなどで使う色を、8色から選びます。 |
   | アイコン | カテゴリのアイコンを選びます。 |

3. 右上の「保存」をタップします。

![カテゴリを追加画面](https://raw.githubusercontent.com/shibatype1999/assett-manual/main/images/ja/category-form.png)

> **ポイント**
> - カテゴリの通貨に既定通貨以外を選んだ場合、その通貨のレートは「設定」タブの「通貨・レート」で確認・変更できます（→ [通貨と為替レート](currency)）。
> - ローンやクレジットカードの未払い残高などは、「負債として扱う」を ON にしたカテゴリで管理すると、総資産から差し引かれます。

## カテゴリを編集する

1. 「カテゴリ」タブで、編集したいカテゴリをタップします。
2. 「カテゴリを編集」画面で内容を変更し、「保存」をタップします。

## カテゴリを並べ替える

カテゴリの右側にある「≡」を長押ししたまま、上下にドラッグします。
ここでの並び順は、「入力」タブやチャートのカテゴリの並び順にも反映されます。

## カテゴリを削除する

1. 「カテゴリ」タブの右上にある編集ボタン（鉛筆のアイコン）をタップします。
2. 削除したいカテゴリの右側にあるゴミ箱のアイコンをタップします。
3. 確認画面で「削除」をタップします。
4. 削除が終わったら、右上の完了ボタン（✓）をタップします。

> **ご注意**
> カテゴリを削除すると、そのカテゴリの**記録もすべて削除**され、元に戻せません。
> 必要に応じて、事前にバックアップを取ってください（→ [データのバックアップと復元](backup)）。

## 最初から用意されているカテゴリについて

はじめて起動したときは「銀行」「株」「不動産」の3つが用意されています。
これらは自由に編集・削除できます。名前を変更していない場合、アプリの表示言語を切り替えると、カテゴリ名もその言語に切り替わります。
